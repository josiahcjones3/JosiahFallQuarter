1. What is Git, what is Github, and what is the difference between the two? Git a  version control system that tracks changes in your code. Github is a website where you upload your code. Git tracks the changes in your code.
2. What is the difference between a local repository and a remote repository? Local exist on your computer and Remote exist on the internet on Github.com.
3. What does the push command do in Git? It uploads the changes from your local repo to your remote repo.
4. What does the commit command do in Git? Saves the file in your local repo.
5. What is Github Desktop, & why are we using it? Is a desktop app that lets you use Git and Github without having to type Git commands in the terminal.
